## 📋 Project Description

LinguaX is a **portfolio-grade** web application that translates text between 19+ languages using the free **MyMemory Translation API**. It features a stunning cyberpunk/glassmorphism UI with animated backgrounds, neon glow effects, and smooth micro-interactions.

## ✨ Features

### Core Translation

* 🔤 Input text area with 5,000 character limit
* 🌍 19+ language pairs
* ⚡ Auto-detect source language
* 🔄 Swap languages with animation
* 🚀 Translate button with glowing UI

### Advanced Features

* ⌨️ Typing effect output
* 📊 Confidence bar
* 📋 Copy to clipboard
* 🔊 Text-to-speech
* 🔢 Character counter
* ⏳ Loading animation
* 📚 Translation history (localStorage)
* ♻️ Restore from history
* ⚠️ Error handling

### UI/UX

* 🌌 Animated background
* 🌟 Floating orbs & particles
* 🪟 Glassmorphism panels
* 💡 Neon glow effects
* 🎯 Split-screen layout
* 📱 Fully responsive
* ⌨️ Keyboard shortcut (Ctrl/Cmd + Enter)

## ⚙️ API

LinguaX uses the **MyMemory Translation API**

* ✅ No API key required
* ✅ Works directly in browser
* ✅ No CORS issues
* ⚠️ Limit: ~5,000 characters/day
