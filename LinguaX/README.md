# ⬡ LinguaX — Neural Translation Interface

A modern language translation web application built using HTML, CSS, and JavaScript. LinguaX enables users to translate text across multiple languages through an intuitive and responsive interface.

## 🌐 Live Demo

https://sparkling-dusk-f29c0c.netlify.app/

## 📌 Overview

LinguaX is a browser-based translation tool that uses the MyMemory Translation API to provide quick and accurate translations. The application focuses on usability, responsiveness, and a clean user experience.

## 🚀 Features

* Translate text between 19+ languages
* Auto-detect source language
* Swap source and target languages
* Copy translated text to clipboard
* Text-to-speech support
* Translation history using localStorage
* Character counter
* Responsive design for desktop and mobile
* Keyboard shortcut support (Ctrl/Cmd + Enter)

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (ES6)
* MyMemory Translation API
* Web Speech API
* localStorage

## ▶️ Run Locally

1. Open the project in VS Code
2. Install the Live Server extension
3. Run `index.html` using Live Server
