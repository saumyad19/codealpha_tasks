# 🛍️ ShopSphere — AI FAQ Chatbot

An intelligent FAQ chatbot for e-commerce platforms built using **JavaScript and NLP techniques (TF-IDF + Cosine Similarity)**.

---

## 🌐 Live Demo

https://illustrious-chaja-e4b5f6.netlify.app/

---

## 📌 Overview

ShopSphere is a browser-based chatbot that answers user queries by matching them with predefined FAQs using **Natural Language Processing (NLP)** techniques.
It simulates an AI assistant experience with a clean, responsive UI.

---

## 🚀 Features

* 💬 Chat-style interface (real-time interaction)
* 🧠 NLP-based query matching
* 📐 TF-IDF + Cosine Similarity algorithm
* 📚 20 predefined FAQs across multiple categories
* 🔍 Query preprocessing (tokenization, stopword removal)
* 📱 Fully responsive design
* ⚡ Fast and lightweight (no external libraries)

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (ES6)
* NLP (TF-IDF, Cosine Similarity)

---

## 🧠 How It Works

1. User enters a query
2. Text is preprocessed (lowercase, tokenized, cleaned)
3. TF-IDF vector is generated
4. Cosine similarity is computed with stored FAQs
5. Best matching answer is returned
